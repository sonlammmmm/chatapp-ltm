Java làm nền. TCP kết nối.

JAVA 11+

Swing + FlatLaf

Giao diện máy khách và bảng điều khiển máy chủ.

TCP SOCKET

JSON + Gson

Packet thống nhất cho xác thực, chat, phòng và báo hiệu.

DỮ LIỆU

SQLite + JDBC

Lưu tài khoản, salt và giá trị băm mật khẩu.

JSON là định dạng: biểu diễn dữ liệu dạng văn bản theo cặp khóa–giá trị, ví dụ {"type":"MSG_DIRECT"}.

Gson là thư viện Java: chuyển đối tượng Packet thành chuỗi JSON khi gửi và chuyển JSON về Packet khi nhận.

Packet (Java) → Gson.toJson() → JSON qua TCP → Gson.fromJson() → Packet (Java)

Vì sao dùng cả hai? JSON thống nhất cách biểu diễn dữ liệu; Gson tự động chuyển đổi, tránh ghép chuỗi và tách dữ liệu thủ công.

Nêu đúng những gì đã triển khai.

MẬT KHẨU

SHA-256 + salt

Salt ngẫu nhiên 16 byte; dữ liệu tài khoản lưu trong SQLite.

TIN NHẮN

AES-128-CBC

Nội dung chat được mã hóa với IV ngẫu nhiên; khóa mặc định dùng chung.

GIỚI HẠN

Tệp gửi byte trực tiếp

Luồng P2P hiện chưa mã hóa tệp; chưa có trao đổi khóa theo phiên.

Hướng nâng cấp: TLS / mã hóa có xác thực, khóa theo phiên và hàm băm mật khẩu chuyên dụng.
